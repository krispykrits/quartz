# Comparisons and Distinctions

## Representations

| Item | Meaning | Common confusion |
|---|---|---|
| State | World configuration | Not the same as a node |
| Node | Search-tree record for a path | Multiple nodes can share a state |
| State space | Graph defined by the problem | Exists conceptually before search |
| Search tree | Paths generated by an algorithm | Can be infinite over a finite graph |
| Frontier | Reached, unexpanded nodes | Not all reached states |

## Algorithms

| Strategy | Priority | Complete? | Cost-optimal? | Main issue |
|---|---|---|---|---|
| BFS | depth | Yes under finite $b$ | Equal costs | $O(b^d)$ memory |
| UCS | $g$ | Yes under cost conditions | Yes | Can expand many cheap detours |
| DFS | deepest | Not generally | No | Infinite paths/cycles |
| Iterative deepening | increasing depth limit | Yes on finite acyclic spaces | Equal costs | Re-expansion |
| Greedy | $h$ | Not generally | No | Ignores paid cost |
| A* | $g+h$ | Yes under conditions | Yes with required heuristic conditions | Memory/time |
| Weighted A* | $g+Wh$ | Often used satisficingly | Generally no exact optimum | Quality-speed tradeoff |

## Admissible vs. Consistent

| Admissible | Consistent |
|---|---|
| Never overestimates $h^*$ | Obeys edge triangle inequality |
| Global lower-bound statement | Local edge-by-edge statement |
| Supports A* tree-search proof | Supports monotone $f$ and graph-search closure |
| Implied by consistency | Does not alone imply consistency |

## Early vs. Late Goal Test

BFS with equal costs can test on generation. UCS/A* must test when popping the best-priority node; discovery alone does not prove cheapest arrival.

## Max vs. Sum of Heuristics

`max` of admissible heuristics is admissible. Sum is unsafe when components count overlapping work; disjoint pattern databases/cost partitioning justify addition.
