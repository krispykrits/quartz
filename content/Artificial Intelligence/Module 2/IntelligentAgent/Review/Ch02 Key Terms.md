# Chapter 2 — Key Terms

  -----------------------------------------------------------------------
  Term                                Lecture-grounded meaning / reminder
  ----------------------------------- -----------------------------------
  Agent                               perceives through sensors and acts
                                      through actuators

  Percept                             sensor content at one instant

  Percept sequence                    complete history of percepts

  Agent function                      maps percept sequences to actions

  Agent program                       concrete implementation of the
                                      agent function

  Agent architecture                  physical computing/sensor/actuator
                                      substrate

  Rational agent                      selects actions expected to
                                      maximize performance under
                                      available evidence and prior
                                      knowledge

  Performance measure                 objective external criterion for
                                      success over environment states

  Consequentialism                    judging behavior by consequences

  PEAS                                Performance, Environment,
                                      Actuators, Sensors

  Information gathering               actions chosen to modify/improve
                                      future percepts

  Autonomy                            reduced dependence on designer
                                      prior knowledge through
                                      percepts/learning

  Condition-action rule               if-condition-then-action mapping

  Transition model                    how the world evolves and actions
                                      affect it

  Sensor model                        how world state is reflected in
                                      percepts

  Goal                                description of a desirable
                                      situation

  Utility                             graded desirability of world states

  Utility function                    agent's internalization of
                                      performance preferences

  Expected utility                    probability-weighted utility across
                                      possible outcomes

  Model-free agent                    learns which action is best without
                                      learning exactly how actions change
                                      the environment

  Performance element                 selects actions

  Learning element                    modifies knowledge to improve
                                      performance

  Critic                              evaluates performance against
                                      external standard

  Problem generator                   proposes informative exploratory
                                      actions

  Reward / penalty                    direct feedback singled out by the
                                      performance standard

  Atomic representation               state as indivisible identity

  Factored representation             state as fixed attributes/variables

  Structured representation           objects, attributes, and relations

  Expressiveness                      capacity to represent more
                                      structure/information, often more
                                      concisely

  Localist representation             one-to-one concept-to-memory
                                      mapping

  Distributed representation          concept spread over many memory
                                      locations
  -----------------------------------------------------------------------

episodic/sequential; static/dynamic/semidynamic; discrete/continuous;
known/unknown.
