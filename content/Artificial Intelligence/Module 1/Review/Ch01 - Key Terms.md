# Chapter 1 - Key Terms
| Term | Meaning |
|---|---|
| Cognitive modeling | programs as testable models of human thought |
| Turing test | behavioral indistinguishability from a human in text interaction |
| Rational agent | selects actions for best/best expected outcome |
| Performance measure | criterion defining successful behavior |
| Expected utility | probability-weighted utility |
| Limited rationality | rational choice under finite resources |
| Value alignment | aligning machine objectives with human objectives |
| Corrigibility | preserving ability to be corrected/deferred |
| Computability | whether any algorithm can solve a problem |
| Tractability | whether a computable problem is feasible |
| Decision theory | probability + utility |
| Game theory | decisions among interacting utility-maximizing agents |
| MDP | states, actions, transitions, rewards, discount |
| Cybernetics | feedback and error correction |
| Microworld | restricted domain used for tractable demonstrations |
| Weak method | general search/reasoning with little domain knowledge |
| Expert system | domain-specific knowledge-intensive rule system |
| Perceptron | linear threshold classifier |
| Backpropagation | gradient-based learning through layered networks |
| Bayesian network | directed probabilistic graphical model |
| Conditional independence | structure enabling local factorization |
| Deep learning | multilayer learned representations |
| King Midas problem | literal objective optimization causing unwanted consequences |
