# Chapter 1 - Comparisons and Distinctions
| Concept A | Concept B | Main Difference |
|---|---|---|
| Thinking humanly | Acting humanly | cognitive fidelity vs behavioral imitation |
| Thinking rationally | Acting rationally | valid inference vs effective action |
| Human-centered | Rationality-centered | empirical resemblance vs engineering performance |
| Logic | Probability | certainty vs graded uncertainty |
| Belief | Preference | what is likely vs what is desirable |
| Perfect rationality | Limited rationality | unlimited vs resource-bounded computation |
| Fixed objective | Assistance model | objective assumed known vs uncertain human objective |
| Computability | Tractability | solvable in principle vs feasible in practice |
| Polynomial | Exponential | slower scaling vs combinatorial explosion |
| Weak methods | Expert systems | general search vs domain knowledge |
| Perceptron | Deep network | linear boundary vs multilayer nonlinear representation |
| Benchmark performance | Robust behavior | bounded score vs open-world dependability |
| Capability | Governance | what AI can do vs how deployment is constrained |

> [!warning]
> Correct inference is not the same as rational action.

> [!warning]
> More computation is not always more rational when computation itself has cost.
