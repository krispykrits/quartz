# AI History and Methodological Shifts
_Source slides: 24-36_

## Timeline
| Period | Milestone |
|---|---|
| 1943 | McCulloch-Pitts |
| 1956 | Dartmouth |
| 1960s | Microworlds |
| 1970s | Reality check |
| 1980s | Expert systems |
| 1986 | Backprop revival |
| 1988 | Bayesian nets + RL |
| 2000s | Big data |
| 2012 | Deep learning surge |
| Today | AI systems everywhere |

## Historical Pattern
```text
broad claims → narrow successes → scale limitations
→ methodological corrections → new computational opportunities
```

## Inception: 1943-1956
McCulloch-Pitts neurons, Hebbian co-activation, SNARC, Turing's work, and the 1956 Dartmouth workshop.

## Early Enthusiasm
Logic Theorist, General Problem Solver, Lisp, Advice Taker, microworlds, and perceptrons.

## Reality Check
Slide 28 emphasizes: introspection is not algorithmic analysis; combinatorial explosion; representation limits.

## Expert Systems and Winter
DENDRAL and MYCIN showed the power of domain knowledge but knowledge acquisition, maintenance, uncertainty, brittleness, and little learning constrained scale.

## Statistical/Learning Turn
Backpropagation, probability, Bayesian networks, reinforcement learning, shared benchmarks, big data, and deep learning shifted methodology toward empirical learning.
