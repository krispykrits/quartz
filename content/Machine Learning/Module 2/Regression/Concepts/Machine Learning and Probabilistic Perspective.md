# Machine Learning and Probabilistic Perspective

_Source slides: 3–5_

## Mitchell's Definition

Machine learning is described using:

- **T — Task**
- **P — Performance**
- **E — Experience**

A program learns if experience improves its measured performance on the task.

## Probabilistic Perspective

The lecture treats every unknown quantity—such as future observations or model parameters—as a random variable represented by a probability distribution.

## Why Probability?

1. It provides a framework for optimal decisions under uncertainty.
2. It provides a common language connecting ML to control theory, econometrics, information theory, statistical physics, and other fields.

> [!important]
> Probability is not introduced merely as a way to report confidence. It becomes a unifying language for modeling unknown quantities and fitting models.
