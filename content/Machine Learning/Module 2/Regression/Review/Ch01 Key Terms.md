# Key Terms

- **Task (T):** what the learner must do.
- **Performance (P):** how success is measured.
- **Experience (E):** training signal/data through which performance improves.
- **Feature / covariate / predictor:** input variable $x$.
- **Label / target / response:** supervised output $y$.
- **Design matrix:** $N\times D$ matrix of examples and features.
- **Logit:** unnormalized class score before softmax.
- **Loss:** numerical cost of a prediction.
- **Empirical risk:** average observed training loss.
- **Population risk:** expected loss under the true data distribution.
- **Generalization:** performance on unseen/future data.
- **Overfitting:** training performance substantially better than future performance.
- **Inductive bias:** model assumptions/preferences that favor some solutions.
- **Likelihood:** probability the model assigns to observed data.
- **NLL:** negative log-likelihood.
- **Residual:** observed minus predicted regression value.
- **Latent factor:** unobserved variable explaining observed variation.
- **Self-supervision:** proxy prediction targets derived from unlabeled data.
- **Policy:** RL mapping from state to action.
- **Credit assignment:** determining which actions caused delayed reward.
- **TF-IDF:** term weighting based on local frequency and corpus rarity.
- **OOV:** out-of-vocabulary.
- **MCAR / MAR / NMAR:** missing-data mechanisms.
