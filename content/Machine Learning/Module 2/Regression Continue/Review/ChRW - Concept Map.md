# Concept Map

```text
Training Regression Models
├─ Linear Regression
│  ├─ MSE / RMSE / MAE
│  ├─ Normal Equation
│  └─ Gradient Descent
│     ├─ Batch GD
│     ├─ Stochastic GD
│     └─ Mini-batch GD
├─ Polynomial Regression
│  ├─ Feature expansion
│  ├─ Underfitting / Overfitting
│  └─ Learning Curves → Bias / Variance
├─ Regularization
│  ├─ Ridge (L2)
│  ├─ Lasso (L1)
│  ├─ Elastic Net
│  └─ Early Stopping
└─ Classification extensions
   ├─ Logistic Regression → Sigmoid → Decision Boundary
   └─ Softmax Regression → Multiple classes → Cross Entropy
```
