# Key Terms
- **Machine learning:** algorithms that improve automatically through experience.
- **Task (T):** what the program is meant to perform.
- **Performance measure (P):** how performance is evaluated.
- **Experience (E):** training experience from which it learns.
- **Credit assignment problem:** under indirect feedback, determining which earlier actions deserve credit/blame for the final outcome.
- **Target function:** function the learner seeks to learn.
- **Function approximation:** learning a practical approximation to a target function.
- **Representation:** form used to express candidate target-function approximations.
- **LMS:** incremental weight-update procedure used in the checkers example.
- **Hypothesis space H:** candidate hypotheses searched by the learner.
- **Search strategy:** procedure used to move through H.
- **Performance System / Critic / Generalizer / Experiment Generator:** four modules in the final checkers design.
