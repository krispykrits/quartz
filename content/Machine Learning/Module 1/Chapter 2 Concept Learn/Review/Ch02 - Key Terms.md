# Chapter 2 - Key Terms

| Term | Definition |
|---|---|
| Concept learning | Inferring a Boolean-valued function from training examples |
| Target concept $c$ | Unknown Boolean function to learn |
| Instance space $X$ | Set of possible inputs |
| Hypothesis $h$ | Candidate description of the concept |
| Hypothesis space $H$ | Set of allowed hypotheses |
| `?` | Any attribute value is acceptable |
| `∅` | No attribute value is acceptable |
| General-to-specific ordering | Partial order based on positive-set containment |
| Consistent hypothesis | Agrees with every example in D |
| Version space | All hypotheses in H consistent with D |
| S boundary | Maximally specific version-space members |
| G boundary | Maximally general version-space members |
| Minimal generalization | Smallest move toward greater generality |
| Minimal specialization | Smallest move toward greater specificity |
| Candidate Elimination | Algorithm maintaining S and G |
| Active learning | Choosing informative examples to query |
| Inductive bias | Assumptions enabling generalization beyond observed data |
