# Computational Neuron Models
*Source: slides 18–21, 85–94.*

| Model | Main abstraction |
|---|---|
| Multi-compartment biophysical | Detailed morphology and channel/receptor dynamics |
| Integrate-and-fire | Integration, threshold, spike/reset |
| Izhikevich | Phenomenological realistic spiking |
| Rate | Summed input + response function |
| Threshold | Summed input + all-or-none response |

$$s_i=\sum_j w_{ij}x_j,\qquad y_i=f(s_i)$$

## Exam-Level Understanding
Know what biological detail each model preserves or discards.
