# Neural Coding
*Source: slides 22–28.*

- Discrimination: classification-like threshold response.
- Tuning: strong response over a preferred range.
- Spatial discrimination: pattern across inputs.
- Temporal discrimination: spike sequence.
- Spatiotemporal discrimination: input identity and timing jointly.
- Rate coding: firing frequency.
- Temporal coding: repeatable spike timing.
- Synchrony coding: coordinated timing; slide 28 links this to the binding problem.

> [!important]
> The same number of spikes can produce different responses when their spatiotemporal arrangement differs.
