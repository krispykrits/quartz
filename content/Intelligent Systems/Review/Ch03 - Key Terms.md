# Chapter 3 - Key Terms

| Term | Exam-ready definition |
|---|---|
| Synapse | Directed junction where one neuron influences another. |
| Membrane potential | Voltage across a neuron's membrane. |
| Resting potential | Baseline negative potential, roughly -65 to -90 mV in the lecture. |
| Action potential | Brief regenerative voltage spike after threshold. |
| Refractory period | Temporary post-spike period preventing immediate refiring. |
| EPSP | Excitatory postsynaptic potential. |
| IPSP | Inhibitory postsynaptic potential. |
| Saltatory conduction | Myelin limits leakage and nodes regenerate the spike. |
| Dale's Law | Biological neuron excites all targets or inhibits all targets according to neurotransmitter. |
| Rate coding | Information represented by firing frequency. |
| Temporal coding | Information represented by spike timing. |
| CPG | Network generating repeating activity for periodic behavior. |
| WTA | Competitive network where one neuron dominates via lateral inhibition. |
| Hebbian learning | Synaptic change based on co-activity. |
| STDP | Plasticity based on relative pre/post spike timing. |
| Receptive field | Sensory region influencing a neuron's response. |
| Retinotopy | Preservation of spatial relationships in neural mapping. |
| Place cell | Hippocampal neuron with location-related firing. |
| Grid cell | Spatial neuron with grid-pattern firing fields. |
| Rich club | Highly connected core of high-degree nodes. |
| Structural connectivity | Physical/anatomical connections. |
| Functional connectivity | Dynamical/statistical coupling or influence. |
