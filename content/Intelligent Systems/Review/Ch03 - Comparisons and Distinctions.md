# Chapter 3 - Comparisons and Distinctions

| Pair | Key distinction |
|---|---|
| Presynaptic / postsynaptic | Sender / receiver |
| EPSP / IPSP | Excitatory / inhibitory PSP |
| PSP / action potential | Graded input / regenerative spike |
| Tuning / discrimination | Preferred-range measurement / classification |
| Rate / temporal coding | Firing frequency / precise spike pattern |
| Feed-forward / recurrent | No feedback / feedback |
| Biological neuron / ANN unit | Dale's Law vs mixed positive/negative weights |
| Basic Hebb / gated Hebb | Unstable co-activity vs weight-dependent stabilization |
| Pre- / postsynaptic gating | Gate \(y_j\) / gate \(y_i\) |
| Place / grid cell | Location-specific / periodic grid-like fields |
| Ligand- / voltage-gated | Chemical binding / membrane voltage |
| Structural / functional connectivity | Anatomy / dynamical-statistical relationship |
| Segregation / integration | Separate community processing / coordinated processing |
