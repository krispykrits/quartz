# Criteria-Based and Human-Based Test Design
**Source:** Sections 2.5.1 and 2.6.

| Criteria-based | Human-based |
|---|---|
| Uses engineering goals such as coverage criteria | Uses domain/user/testing knowledge |
| Mathematical/technical | Empirical/contextual |
| Builds/manipulates abstract models | Seeks likely problematic situations |
| Requires discrete math, programming, testing | Requires application domain, UI, user behavior knowledge |

Human-based designers seek stress tests, very large/small values, boundaries, invalid values, and unusual actions.

## Critical Distinction
The chapter explicitly rejects the idea that criteria-based testing belongs only to unit testing and human-based testing only to system testing. They are **complementary approaches** that can be used at multiple levels.
