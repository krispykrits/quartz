# Software Testing Activities
**Source:** Section 2.2 and Figure 2.2.

A test engineer may design inputs, create test values/scripts, run tests, analyze results, and report findings. The chapter emphasizes that these responsibilities need not belong to one person.

## Core Flow
`Design → executable tests → execute → output/results → evaluate`

A test manager establishes policies/processes and coordinates testing.

## Coverage Criteria
Formal criteria help decide what inputs to use and when test design has reached an adequate stopping point.

## Exam-Level Understanding
Testing is not synonymous with test execution. Design, construction/automation, execution, and evaluation are distinct activities.
